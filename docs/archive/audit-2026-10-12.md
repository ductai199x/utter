## Critical

1. **Hands-free (double tap) never starts, and the next dictation is lost.**
   `crates/utter-platform/src/hotkey.rs:111-118`, `crates/utter-pipeline/src/lib.rs:787-805`.
   The first tap sends `Cancel`, which ends `dictate`; the idle loop then drops `HandsFree` and
   `Finish`. The hotkey machine is left in `HandsFree`, so the next normal hold is taken as the
   stop tap and does nothing. Fix: start a hands-free dictation on `HandsFree` in the idle loop.
   **Status, 2026-10-20: Fixed.** 74206ae: utter-pipeline lib.rs Pipeline::run idle loop matches Action::Start | Action::HandsFree and starts dictate() with hands_free = (action == HandsFree).

## High

2. **The clipboard is lost after two pastes close together.** `utter-platform/src/insert.rs:158-185, 440-448`.
   The restore runs detached; the second paste snapshots dictation 1 as "the user's clipboard"
   and restores it. Word/Outlook/WhatsApp (3 s keep) and Remote Desktop (5 s) hit this. Fix: one
   pending-restore slot that a new paste reuses.
   **Status, 2026-10-20: Fixed.** e3d49db: utter-platform insert.rs paste_by_clipboard keeps one PENDING restore slot; a paste that finds the clipboard still holding the last paste's text (sequence == p.ours) reuses that snapshot and takes the restore over.
3. **History can be wiped.** `utter-pipeline/src/history.rs:104-107, 216-224, 304`. Any read error
   (one torn UTF-8 byte, a sharing violation) loads an empty list and caches it; the next
   favorite/delete rewrites the file with only the new entries. Fix: only NotFound is empty;
   read lossily; never rewrite after a failed load.
   **Status, 2026-10-20: Fixed.** 8611e1a: utter-pipeline history.rs load(): only ErrorKind::NotFound is an empty list, text read with from_utf8_lossy, a failed read is returned and not cached; History/Settings UI show the read error.
4. **A lost microphone is never detected or recovered.** `utter-audio/src/lib.rs:121, 186-193, 250`.
   Unplugging a USB mic or a sleeping Bluetooth headset freezes the pre-roll; every dictation then
   gets the same stale 300 ms ("Didn't catch that"), silently, until restart.
   **Status, 2026-10-20: Fixed.** cb471e2 (+60c08b7): utter-audio marks the mic dead on DeviceNotAvailable/StreamInvalidated/HostUnavailable/PermissionDenied or 1 s without audio and clears its history; Pipeline::check_microphone reopens it every 2 s and posts "Microphone disconnected"/"connected" notices.
5. **A press while the pipeline is busy loses speech.** `utter-pipeline/src/lib.rs:787, 1029, 1054`.
   Key-down time is discarded; recording starts when the loop gets to it (after a cleanup of up to
   3 s), with only 300 ms of pre-roll.
   **Status, 2026-10-20: Fixed.** cb471e2: Start{at} carries the key-down Instant into source.start(at); utter-audio keeps 10 s of timestamped history so recording starts from key down (minus pre-roll) even if the loop was busy; stop(until) ends at key up.
6. **llama-server crashes are never noticed.** `utter-llm/src/lib.rs:243-273`, `utter-pipeline/src/clean.rs:92-121`.
   After a driver reset or out-of-memory crash, every dictation pastes the raw transcript until
   Utter restarts; no notice. Fix: liveness check, restart with backoff, a Bar notice.
   **Status, 2026-10-20: Fixed.** 1dd7db6: utter-pipeline clean.rs cleanup worker supervises llama-server (health check every 5 s and after any failure, restart with waits 1/5/30/60 s, warm-up), answers at once while down, and Pipeline::report_cleanup_health shows "Cleanup stopped: restarting it" / "Cleanup is back".
7. **The Bar stays on screen after the pipeline fails mid-dictation.** `app/src-tauri/src/main.rs:382-391`.

   **Status, 2026-10-20: Fixed.** 0276d55: app/src-tauri main.rs run_pipeline error path calls bar.stopped("Dictation stopped"), which clears `listening` and leaves with an error (level feed stops, Bar hides).
8. **The Bar collapses into an empty waveform while fading out.** `app/src/bar/Bar.svelte:64-77, 152, 169-175`.

   **Status, 2026-10-20: Fixed.** 0276d55: app/src/bar/Bar.svelte draws exit/cancelled as a fade-out of the last drawn state (words, check, notice kept) instead of a bare waveform.
